# System-Derived Values Display Update

The raw JSON previously shown after a transaction assessment has been replaced with an expandable professional table.

The table now shows:

- Historical Average Unit Price
- Vendor Tenure at Purchase
- Portfolio Average Payment Delay
- Historical Transactions
- Average Invoice Amount
- Shared Identity Signal

Each field includes its formatted value, data source, and a short business explanation. Missing historical data is shown honestly rather than as a misleading zero or placeholder. Shared identity remains clearly marked as an investigation signal only.
